  TÍNH NĂNG MỚI
═══════════════════════════════════════════════════════════════════

🎯 XỬ LÝ ĐỆ QUY (RECURSIVE PROCESSING)

   Cấu trúc PowerPoint phức tạp:
   
   Slide
   ├── TextBox A (English) ← XỬ LÝ ✓
   ├── Group 1
   │   ├── TextBox B (English) ← XỬ LÝ ✓ (NEW!)
   │   └── TextBox C (Việt) ← XỬ LÝ ✓ (NEW!)
   └── Group 2
       └── Group 2.1 (nested)
           ├── TextBox D (English) ← XỬ LÝ ✓ (NEW!)
           └── TextBox E (Việt) ← XỬ LÝ ✓ (NEW!)
   
   → Không giới hạn cấp độ nested
   → Không bỏ sót textbox nào


🎯 TÙY CHỌN XỬ LÝ LINH HOẠT

   Mode 1: XỬ LÝ CẢ HAI
   ├─ Xóa hình ảnh theo kích thước
   └─ Lọc text (giữ Việt/giữ Anh)
   
   Mode 2: CHỈ XÓA HÌNH ẢNH
   ├─ Xóa ảnh theo kích thước
   └─ KHÔNG động vào text
   
   Mode 3: CHỈ LỌC TEXT
   ├─ KHÔNG động vào ảnh
   └─ Lọc text (giữ Việt/giữ Anh)

  HƯỚNG DẪN SỬ DỤNG
═══════════════════════════════════════════════════════════════════

📥 BƯỚC 1: TẢI VÀ GIẢI NÉN
   → PowerPoint_Cleaner_v3.0_FINAL.zip

📥 BƯỚC 2: CÀI ĐẶT

   Windows:
   1. Giải nén file ZIP
   2. Double click: install.bat
   3. Chờ cài đặt xong (vài giây)
   
   Mac/Linux:
   1. Giải nén file ZIP
   2. Mở Terminal trong folder
   3. Chạy: bash install.sh
   4. Chờ cài đặt xong

📥 BƯỚC 3: SỬ DỤNG

   A. XỬ LÝ 1 FILE:
      Windows: Double click run.bat
      Mac/Linux: bash run.sh
   
   B. XỬ LÝ NHIỀU FILE:
      Windows: Double click run_batch.bat
      Mac/Linux: bash run_batch.sh

📥 BƯỚC 4: CẤU HÌNH

   1. Chọn file PowerPoint
   
   2. Chọn chế độ xử lý:
      ○ Xử lý CẢ HAI
      ○ CHỈ xóa hình ảnh
      ○ CHỈ lọc text
   
   3. Cấu hình chi tiết:
      - Tab "Xóa hình ảnh": Nhập kích thước
      - Tab "Lọc text": Chọn giữ Việt hay Anh
   
   4. Click "▶ XỬ LÝ FILE" hoặc "▶ XỬ LÝ TẤT CẢ FILES"
   
   5. Xem kết quả trong Result Window

  DEMO TÌNH HUỐNG

🔍 CASE 1: CHỈ CẦN XÓA LOGO

   Slide có:
   - Logo 1.6x1.6 inch (nhiều chỗ)
   - Text tiếng Việt và tiếng Anh (cần giữ)
   
   Cấu hình:
   ✓ Chế độ: "CHỈ xóa hình ảnh"
   ✓ Width: 1.6, Height: 1.6
   ✓ Tolerance: 0.01
   
   Kết quả:
   ✅ Xóa hết logo
   ✅ Giữ nguyên tất cả text


🔍 CASE 2: CHỈ CẦN DỊCH SANG TIẾNG VIỆT

   Slide có:
   - Hình ảnh (cần giữ)
   - Text tiếng Việt (cần giữ)
   - Text tiếng Anh (cần xóa)
   
   Cấu hình:
   ✓ Chế độ: "CHỈ lọc text"
   ✓ Chọn: "Giữ tiếng Việt - Xóa tiếng Anh"
   
   Kết quả:
   ✅ Giữ nguyên hình ảnh
   ✅ Giữ text tiếng Việt
   ✅ Xóa text tiếng Anh (KỂ CẢ trong groups!)


🔍 CASE 3: LÀM SẠCH TOÀN BỘ

   Slide có:
   - Logo 1.6x1.6 inch (cần xóa)
   - Text tiếng Việt (cần giữ)
   - Text tiếng Anh (cần xóa)
   
   Cấu hình:
   ✓ Chế độ: "Xử lý CẢ HAI"
   ✓ Ảnh: Width 1.6, Height 1.6
   ✓ Text: "Giữ tiếng Việt"
   
   Kết quả:
   ✅ Xóa logo
   ✅ Giữ text tiếng Việt
   ✅ Xóa text tiếng Anh
