    WINDOWS:
    1. Tải và giải nén ZIP
    2. Double click: install.bat  (chờ vài giây)
    3. Double click: run_batch.bat
    4. Chọn chế độ xử lý
    5. Thêm files → Xử lý
    
    MAC/LINUX:
    1. Tải và giải nén ZIP
    2. Terminal: bash install.sh
    3. Terminal: bash run_batch.sh
    4. Chọn chế độ xử lý
    5. Thêm files → Xử lý
