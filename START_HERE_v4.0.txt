═══════════════════════════════════════════════════════════════════

🚀 HƯỚNG DẪN NHANH (2 BƯỚC):


BƯỚC 1: CÀI ĐẶT
────────────────
Windows:
   Double-click: install_full.bat
   Chờ vài phút...

Mac/Linux:
   Terminal: bash install_full.sh
   Chờ vài phút...


BƯỚC 2: CHẠY
────────────
Windows:
   Double-click: run_launcher.bat

Mac/Linux:
   Terminal: bash run_launcher.sh

→ Cửa sổ Launcher hiện ra
→ Click chọn tool muốn dùng
→ Hoàn tất!


═══════════════════════════════════════════════════════════════════

💡 HOẶC BUILD THÀNH FILE EXE (Không cần Python):


Windows:
────────
1. Chạy: build_all_exe.bat
2. Chờ 5-10 phút
3. Lấy file EXE trong folder 'dist':
   - ToolLauncher.exe
   - PowerPointCleaner.exe
   - PowerPointCleanerBatch.exe
   - StrokeOrderDownloader.exe

4. Double-click ToolLauncher.exe để dùng

❓ CÂU HỎI:

Q: Tôi không có Python?
A: Build thành EXE (chạy build_all_exe.bat) hoặc tải EXE có sẵn

Q: Chỉ muốn dùng 1 tool?
A: Có thể chạy trực tiếp: python ppt_cleaner.py

Q: Làm sao tải ảnh chữ Hán?
A: Launcher → Stroke Order → Nhập ký tự → Tải

Q: File EXE ở đâu?
A: Sau khi build xong, trong folder 'dist'
