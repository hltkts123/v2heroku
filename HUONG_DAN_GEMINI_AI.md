# HUONG DAN SU DUNG GEMINI AI OCR

## Tinh nang moi: Nhan dang chu Han tu anh bang AI

Phien ban nay tich hop Google Gemini AI de tu dong nhan dang chu Han tu anh!

================================================================================

## Cac buoc su dung

### BUOC 1: Lay Gemini API Key (MIEN PHI)

1. Truy cap: https://aistudio.google.com/app/apikey
2. Dang nhap bang tai khoan Google cua ban
3. Click nut **"Create API Key"**
4. Chon **"Create API key in new project"** (neu lan dau)
5. Copy API key (chuoi dai khoang 39 ky tu)

**LUU Y:**
- Gemini API hien tai **MIEN PHI**!
- Co gioi han request (15 request/phut, 1500 request/ngay)
- Du cho su dung ca ngay!

---

### BUOC 2: Cau hinh API Key trong ung dung

1. Mo ung dung
2. Trong phan **"GEMINI AI - NHAN DANG CHU HAN TU ANH"**
3. Dan API key vao o **"Gemini API Key"**
4. Click nut **"Luu API Key"**
5. API key se duoc luu va su dung cho lan sau!

---

### BUOC 3: Chon anh chua chu Han

1. Click nut **"[+] Chon Anh Chua Chu Han"**
2. Chon file anh tu may tinh (PNG, JPG, JPEG, BMP, GIF)
3. Anh se hien thi preview

**Loai anh duoc ho tro:**
- Anh chup man hinh co chu Han
- Anh chup tu sach/tai lieu
- Anh chup bang dien thoai
- Anh quet (scan)

---

### BUOC 4: Nhan dang chu Han bang AI

1. Click nut **"[AI] Nhan Dang Chu Han"**
2. Doi 2-5 giay (AI dang xu ly)
3. Chu Han se tu dong hien thi trong o nhap lieu
4. Chon **"Yes"** de bat dau tai stroke ngay
5. Hoac **"No"** de chinh sua truoc khi tai

---

### BUOC 5: Tai anh stroke

- Chu Han da duoc dien vao o nhap lieu
- Click **">> BAT DAU TAI STROKE <<"** de tai
- Hoac nhan phim **Enter**

## Khac phuc loi

### Loi 1: "Chua cau hinh API key"

**Nguyen nhan:** Chua nhap hoac chua luu API key

**Giai phap:**
1. Lay API key tai: https://aistudio.google.com/app/apikey
2. Dan vao o "Gemini API Key"
3. Click "Luu API Key"

---

### Loi 2: "API key invalid" hoac loi 400

**Nguyen nhan:** API key sai hoac het han

**Giai phap:**
1. Kiem tra lai API key (khong co khoang trang thua)
2. Tao API key moi
3. Luu lai

---

### Loi 3: "Khong tim thay chu Han trong anh"

**Nguyen nhan:** 
- Anh khong co chu Han
- Chu qua mo hoac nho
- Anh qua tam

**Giai phap:**
1. Thu anh ro hon
2. Zoom vao phan co chu
3. Tang do sang cua anh

---

### Loi 4: Rate limit (429)

**Nguyen nhan:** Dung qua nhieu request

**Giai phap:**
- Doi 1 phut roi thu lai
- Gioi han: 15 request/phut

## Cau hoi thuong gap

### Q: Gemini AI co mien phi khong?
**A:** CO! Hoan toan MIEN PHI!

### Q: Co gioi han so request khong?
**A:** Co: 15 requests/phut, 1500 requests/ngay. Du dung ca ngay!

### Q: API key co het han khong?
**A:** Khong het han, nhung Google co the thay doi chinh sach.

### Q: Gemini co nhan dang duoc chu viet tay khong?
**A:** CO! Gemini rat manh trong viec nhan dang chu viet tay.

### Q: Anh mo hoac tam co nhan dang duoc khong?
**A:** Duoc! Nhung anh ro se cho ket qua tot hon.

### Q: Gemini co nhan dang tieng Nhat/Han khong?
**A:** CO! Nhung ung dung nay chi loc lay chu Han (Chinese).

### Q: Co can ket noi internet khong?
**A:** CO! Can internet de goi API.

### Q: API key co bi lo khong?
**A:** API key luu tren may ban, KHONG gui len server nao khac.

### Q: Co the dung nhieu anh cung luc khong?
**A:** Chua ho tro. Hien tai chi xu ly tung anh mot.
