                    *** DUNG GEMINI AI - NHANH NHAT! ***

================================================================================
                            BUOC 1: CAI DAT
================================================================================

1. Cai dat Python (neu chua co):
   https://www.python.org/downloads/
   
   LUU Y: Tick vao "Add Python to PATH"!

2. Mo Command Prompt (Windows) hoac Terminal (Mac/Linux)

3. Di chuyen den thu muc chua code:
   cd duong\dan\den\thu\muc

4. Cai dat thu vien:
   pip install -r requirements.txt

================================================================================
                        BUOC 2: LAY API KEY (1 PHUT)
================================================================================

1. Truy cap: https://aistudio.google.com/app/apikey

2. Dang nhap Google

3. Click "Create API Key"

4. Copy API key (chuoi dai khoang 39 ky tu)

MIEN PHI! KHONG HET HAN!

================================================================================
                        BUOC 3: CHAY UNG DUNG
================================================================================

Trong Command Prompt/Terminal, go:

    python stroke_order_downloader.py

Cua so ung dung se mo ra!

================================================================================
                    BUOC 4: CAU HINH API KEY (30 GIAY)
================================================================================

Trong ung dung:

1. Dan API key vao o "Gemini API Key"

2. Click nut "Luu API Key"

3. XONG! Khong can lam lai nua!

================================================================================
                    BUOC 5: SU DUNG AI (30 GIAY)
================================================================================

1. Click nut "[+] Chon Anh Chua Chu Han"

2. Chon anh co chu Han:
   - Anh chup man hinh
   - Anh sach
   - Anh chup tu dien thoai
   - Bat ky anh nao co chu Han!

3. Click nut "[AI] Nhan Dang Chu Han"

4. Doi 2-5 giay (AI dang xu ly)

5. Chu Han se TU DONG hien thi!

6. Click ">> BAT DAU TAI STROKE <<"

7. XONG!
